Shows a character avatar and editable ID beside every assistant reply; replies can be read aloud with the system voice or your own TTS service (local by default, LAN/remote optional).

The card above is the whole configuration (avatar / ID, size, presets, read-aloud, voice, speech service). All three entries — the avatar popup, Settings → Character avatar, and this page — edit the same local settings.

The full guide, the TTS contract, and screenshots live in the repository README.
