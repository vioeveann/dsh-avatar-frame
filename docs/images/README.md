# 截图目录

主 README 引用的文件（均已就位）：

| 文件名 | 内容 |
| --- | --- |
| `row.png` | 一条回复左侧的头像 + ID，连同「已完成，用时 …」那一行 |
| `bar.png` | 朗读时小喇叭右侧的控制条 |
| `panel.png` | 点头像打开的面板（ID、字号、朗读、引擎、语气、语速、预设） |
| `settings.png` | 设置 → 角色头像整页（含语音服务、诊断） |
| `bundle.png` | 插件详情页（含语音服务区块） |

可选，有更好：

- `demo.gif` — 从点小喇叭读到结束的完整流程，10 秒左右，对新用户最有说服力。

要求：PNG，宽度不小于 1200px（`row.png`、`bar.png` 这类局部图可以窄），深色主题下观感更好。

截图里如果出现真实对话内容，发布前先确认没有不适合公开的信息。
