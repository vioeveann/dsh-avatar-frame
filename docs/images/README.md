# 截图目录

主 README 引用了下面四个文件，把截图按这些名字放进来即可（PNG，建议宽度 ≥ 1200px，深色主题下更好看）：

| 文件名 | 内容 |
| --- | --- |
| `row.png` | 一条回复左侧的头像 + ID，连同「已完成，用时 …」那一行 |
| `panel.png` | 点头像打开的设置面板（含 ID、字号、朗读、引擎、语气、语速、预设） |
| `bar.png` | 朗读时输入框上方的播放控制条 |
| `settings.png` | 设置 → 角色头像 那一整页（含诊断） |

可选，但对新用户最有用：

- `demo.gif`：从点小喇叭到读完一段的完整流程，10 秒左右，能大幅提升第一印象；
- `cover.png`：仓库首页大图，可复用 `row.png`。

截图里如果出现真实对话内容，先确认没有不适合公开的信息。
