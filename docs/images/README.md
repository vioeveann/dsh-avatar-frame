# 截图目录

主 README 与 `screenshots.json` 引用的文件（均已就位）：

| 文件名 | 内容 |
| --- | --- |
| `row.png` | 一条回复左侧的头像 + ID，连同「已完成，用时 …」那一行 |
| `bar.png` | 朗读时小喇叭右侧的控制条 |
| `panel.png` / `panel-en.png` | 点头像打开的面板（中 / 英）：ID、字号、朗读、音色、语音服务快捷行、语气、语速、预设 |
| `bundle.png` / `bundle-en.png` | 插件详情页（中 / 英）：开关 + 设置卡片 + 诊断；设置页内容与它一致 |

可选，有更好：

- `demo.gif` — 从点小喇叭读到结束的完整流程，10 秒左右，对新用户最有说服力。

要求：PNG。完整页面图宽度不小于 1200px，弹窗、局部图可以窄；深色主题下观感更好。发版前记得让截图和当前界面一致（音色名、服务区块、诊断按钮都改过）。截图里如果出现真实对话内容，发布前先确认没有不适合公开的信息。
